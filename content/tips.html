避坑建议

  1. 先手写，再用框架。不理解 agent loop 和工具回填就上 LangGraph / CrewAI，出问题时无从下手。
  2. 不要囤教程。主线只选一本（Hello-Agents），其余当查阅资料。上面的清单是索引，不是待办。
  3. 尽早建评估集。agent 开发的难点在“改了之后有没有变好”，没有评估就是凭感觉调 prompt。
  4. 多智能体不是默认选项。先把单 agent + 好工具 + 好上下文做到极致，再评估是否需要拆分。
  5. 关注一手来源。框架迭代快，以官方文档和仓库 README 为准，Star 数只代表热度不代表质量。

关于 AI 生成的教程

  • GitHub 上 2026 年新出现的大量 “agent 教程” 仓库由 AI 批量生成，结构完整但常见问题有：API 已过时、代码跑不通、概念张冠李戴、缺少评估与失败案例。
  • 它们最有价值的用法不是当主教材，而是当源码导读工具：用 PocketFlow-Tutorial-Codebase-Knowledge 或你自己的 coding agent，对 mini-swe-agent、OpenHands、learn-claude-code 生成导读，再对照源码验证。
  • 判断质量的快速方法：看是否有可运行代码和测试、最近是否更新、是否引用一手来源、Issue 区是否有人反馈错误。

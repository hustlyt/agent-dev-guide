推荐主教材：Datawhale《Hello-Agents：从零开始构建智能体》（87k★，中文，16 章）。

它是目前唯一一份同时覆盖原理 → 经典范式手写 → 主流框架 → 自研框架 → 记忆/RAG/上下文工程 → MCP/A2A 协议 → Agentic RL 训练 → 评估 → 综合项目的完整中文教程，深度和广度都够。但它偏“框架与系统”，对 coding-agent 式的 harness 工程（权限、hooks、压缩、子代理、任务系统）和生产级评估讲得少，所以配两份补充材料：learn-claude-code（17 课手写 harness）和 agents-towards-production（生产化），再加 Anthropic 的工程文章作为理论锚点。

推荐组合 一本主教材 + 三份补充

主教材 · 系统

Hello-Agents

中文。ReAct / Plan-and-Solve / Reflection 手写实现，AutoGen / AgentScope / LangGraph 实践，从 0 写框架，Memory、上下文工程、MCP/A2A/ANP、SFT→GRPO、评估、DeepResearch 复现。在线阅读

补充 · Harness 工程

learn-claude-code

80k★。从 while True 循环开始，逐课加入工具、权限、Hooks、TodoWrite、子代理、Skill、上下文压缩、记忆、任务系统、后台任务、Agent Teams、MCP、Goal Loop，共 17 课。

补充 · 进阶 Harness + 评估

Coding Agent from Scratch

Decoding AI 出品。Pydantic AI 实现，含 Docker/Modal 沙箱、LSP、子代理、可观测性、Eval harness、用失败轨迹扩充回归集、轨迹回放。每节配文章+视频。

补充 · 生产化

Agents Towards Production

22k★。工具集成、记忆、部署、多智能体协调、GPU 部署、安全、追踪调试、评估、前端，全部 code-first notebook。

英文读者可把主教材换成 Microsoft AI Agents for Beginners（18 课，有视频）+ Hugging Face Agents Course（有认证），但两者深度都不如 Hello-Agents。

12 周学习路线 每周约 8–10 小时；有 Python 和 LLM API 基础可压缩到 8 周

P0第 1 周

LLM API 与工具调用基础

  • Anthropic Courses：anthropic_api_fundamentals → tool_use（工具调用最清楚的入门）
  • Hello-Agents 第 1–3 章：智能体定义、发展史、LLM 基础
  • 可选：Prompt Engineering 交互教程
✔ 产出：不用任何框架，手写一次“模型 → tool_call → 执行 → 回填结果 → 再调用”的往返。
P1第 2 周

Agent 原理与经典范式

  • 必读：Anthropic · Building Effective Agents（workflow 与 agent 的区别、5 种模式）
  • 必读：Lilian Weng · LLM Powered Autonomous Agents、ReAct 论文
  • Hello-Agents 第 4 章：手写 ReAct、Plan-and-Solve、Reflection
  • 对照：agentic-patterns-course（从零实现 Reflection / Tool / Planning / Multi-agent 四种模式）
  • 读源码：mini-swe-agent（约 100 行能解 GitHub issue 的 agent）
✔ 产出：自己的 ReAct agent，带 3 个工具，能处理工具报错并重试。
P2第 3–4 周

从零手写 Agent Harness（核心阶段）

  • learn-claude-code s01–s17 全部跑一遍并改写：Agent Loop → Tool Use → Permission → Hooks → TodoWrite → Subagent → Skill → Context Compact → Memory → Task System → Background → Cron → Agent Teams → MCP → Integrated Harness → Workflow → Goal Loop
  • 配读：Writing effective tools for agents、Claude Code best practices
  • 原则：12-Factor Agents（自己掌控 prompt、上下文窗口和控制流）
  • 第二份可读源码：mini-harness（约 1400 行，含 goal 模式、AI 权限判官、MCP、子代理），对照自己的实现找差距
  • 长任务：Harness design for long-running application development
✔ 产出：一个能读写文件、跑 shell、需要确认才执行危险命令、会压缩上下文的命令行 coding agent。
P3第 5–6 周

主流框架与 SDK

  • Hello-Agents 第 5–7 章：Coze / Dify / n8n 低代码，AutoGen / AgentScope / LangGraph，自研 HelloAgents 框架
  • LangChain Academy module 0–6（LangGraph 状态图、持久化、人在回路）
  • 选 1–2 个 SDK 深入：OpenAI Agents SDK · Claude Agent SDK · Google ADK · Pydantic AI · smolagents
  • 横向对比：HF Agents Course Unit 2（smolagents / LlamaIndex / LangGraph 同一问题三种写法）
✔ 产出：把 P2 的 agent 用一个框架重写，写一页笔记对比“框架帮你做了什么、藏了什么”。
P4第 7 周

上下文工程、记忆、RAG 与协议

  • Hello-Agents 第 8–10 章 + Extra02 上下文工程补充
  • Anthropic · Effective context engineering for AI agents、The State of Context Engineering（上下文失效类型与修复）
  • 工具规模化：Code execution with MCP、Advanced tool use
  • Microsoft 课程第 5、11、12、13 课（Agentic RAG、MCP/A2A/NLWeb、上下文工程、记忆）
  • MCP for Beginners + MCP 规范；A2A 协议
  • 记忆系统参考实现：mem0、Letta (MemGPT)
✔ 产出：给自己的 agent 写一个 MCP server，并加跨会话长期记忆。
P5第 8 周

多智能体系统

  • 正反两面一起读：Anthropic · How we built our multi-agent research system 与 Cognition · Don't Build Multi-Agents，再读它的续篇 Multi-Agents: What's Actually Working（结论：多个 agent 贡献智能，写操作保持单线程）
  • Hello-Agents 第 14 章（DeepResearch 复现）、第 15 章（赛博小镇）
  • handy-multi-agent（基于 CAMEL 的中文多智能体教程）
  • 框架：CrewAI、Microsoft Agent Framework、OpenAI Swarm（教学用，看 handoff 设计）
✔ 产出：orchestrator + 并行子代理的研究型 agent，并测量它比单 agent 多花多少 token、多拿多少分。
P6第 9–10 周

评估、可观测性与安全

  • 必读：Anthropic · Demystifying evals for AI agents
  • Hello-Agents 第 12 章（指标、基准、评估框架）
  • Coding Agent from Scratch 课程第 7–8 篇：benchmark 与回归测试、用失败轨迹扩充回归集、轨迹回放
  • HF Agents Course Bonus Unit 2（追踪与评估）
  • 工具：Langfuse / Phoenix（追踪），Inspect（评估框架）
  • 基准：SWE-bench、τ²-bench
  • 安全：Microsoft 课程第 6、18 课（可信 Agent、Agent 安全）；agents-towards-production 安全章节
✔ 产出：给自己的 agent 建 30+ 条评估用例，改 prompt 或换模型后能自动出对比报告。
P7第 11 周

生产部署

  • agents-towards-production：部署、GPU 部署、UI、追踪
  • OpenAI · A Practical Guide to Building Agents（PDF，guardrails 与编排）
  • 模板：Agent Starter Pack（含 CI/CD 与评估）、Claude Quickstarts
  • Microsoft 课程第 10、16、17 课（生产、可扩展部署、本地 Agent）
✔ 产出：agent 以无头服务方式部署，能由 webhook / cron 触发，带追踪和费用监控。
P8第 12 周

进阶：Agentic RL 与前沿

  • Hello-Agents 第 11 章：SFT → GRPO 训练智能体
  • Agent Lightning（用 RL 训练已有 agent）
  • HF Agents Course Bonus Unit 1（微调函数调用模型）
  • UC Berkeley LLM Agents MOOC（讲座覆盖推理、规划、代码 agent、安全）
  • 论文索引：LLM-Agent-Paper-List
✔ 产出：读懂并复现一篇 agent 训练论文的小规模实验。

毕业项目建议 选一个，把前面所有阶段串起来

  1. 个人 coding agent：P2 的 harness + MCP + 子代理 + 评估集（用 SWE-bench Lite 子集打分）。
  2. 深度研究 agent：对照 Hello-Agents 第 14 章与 Anthropic 多智能体文章，做引用可追溯的研究报告生成器。
  3. 业务 agent：客服 / 运维 / 数据分析场景，用 τ²-bench 的思路设计“工具 + 用户模拟器 + 策略约束”评测。

Hello-Agents 第 16 章和它的 共创项目 目录里有大量往届示例可参考。

关于 AI 生成的教程

  • GitHub 上 2026 年新出现的大量 “agent 教程” 仓库由 AI 批量生成，结构完整但常见问题有：API 已过时、代码跑不通、概念张冠李戴、缺少评估与失败案例。
  • 它们最有价值的用法不是当主教材，而是当源码导读工具：用 PocketFlow-Tutorial-Codebase-Knowledge 或你自己的 coding agent，对 mini-swe-agent、OpenHands、learn-claude-code 生成导读，再对照源码验证。
  • 判断质量的快速方法：看是否有可运行代码和测试、最近是否更新、是否引用一手来源、Issue 区是否有人反馈错误。

避坑建议

  1. 先手写，再用框架。不理解 agent loop 和工具回填就上 LangGraph / CrewAI，出问题时无从下手。
  2. 不要囤教程。主线只选一本（Hello-Agents），其余当查阅资料。上面的清单是索引，不是待办。
  3. 尽早建评估集。agent 开发的难点在“改了之后有没有变好”，没有评估就是凭感觉调 prompt。
  4. 多智能体不是默认选项。先把单 agent + 好工具 + 好上下文做到极致，再评估是否需要拆分。
  5. 关注一手来源。框架迭代快，以官方文档和仓库 README 为准，Star 数只代表热度不代表质量。
